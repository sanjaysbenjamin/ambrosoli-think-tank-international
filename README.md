# Ambrosoli Think Tank International Website

A responsive, premium single-page website for Ambrosoli Think Tank International.

## Stack
- Static HTML/CSS/JavaScript
- No build step or framework required
- Designed for GitHub + Vercel

## Deploy with Vercel
1. Create a GitHub repository, e.g. `ambrosoli-think-tank-international`.
2. Upload `index.html` and this README.
3. In Vercel, choose **Add New → Project** and import the GitHub repository.
4. Deploy with the default settings.
5. Vercel will provide a `vercel.app` production URL.
